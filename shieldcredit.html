🔄 Loan Lifecycle
1
Register RWA
Face value encrypted via fhevmjs · stored as euint64
2
Credit Evaluation
TFHE.ge(score, 550) → ebool eligible — score never revealed
3
Loan Approval
TFHE.and(eligible, validAmount) → TFHE.select disbursement
4
Interest Accrual
TFHE.mul(principal, rate) · TFHE.add(balance, interest) — homomorphic
5
Repayment
TFHE.min(repay, balance) · Gateway decrypts fully-repaid ebool for callback
6
Liquidation Guard
TFHE.gt(balance, threshold) — no front-running possible on encrypted threshold
